# 絵カードライブラリ紹介CM 構成台本(storyboard)

**ファイル**: `promo/cards_movie.mp4`(1920x1080 / 30fps / 30秒 / BGMつき・ナレーションなし)
**用途**: X(Twitter)投稿。「ポータルから絵カードが全部ダウンロードできる」ことの再告知。

## ねらい

- 3秒で「絵カードが862枚もらえる」と伝わること(スクロールを止める)
- **どこから・どうやってダウンロードするか**が、見ただけで再現できること
- CMのテンポ(カットで語る・ダラダラ動かさない)

## 構成(タイムライン)

| 秒 | 役割 | 画 | テロップ |
|---|---|---|---|
| 0.0–3.2 | **フック** | 絵カードが降ってきて画面に敷き詰まる → 着地で白フラッシュ+シェイク | 小学校の外国語<br>**絵カード862枚**、ぜんぶ無料。 |
| 3.2–6.4 | 入口 | ポータルのトップページ(実画面) | 「小学校外国語アプリポータル」から |
| 6.4–10.4 | **手順①** | トップページを下までスクロール → 「🎴 絵カードライブラリ」セクションで停止 → 「ライブラリをひらく ▶」にタップリング | ① トップを下までスクロール |
| 10.4–14.2 | **手順②** | 絵カードライブラリ(cards.html)の全景。カードがずらりと並ぶ | ② 862枚が、ずらり |
| 14.2–18.6 | **手順③** | 検索バーに `apple` と1文字ずつ入力 → 該当カードに絞り込まれる | ③ 英語で検索できる |
| 18.6–23.0 | **手順④** | カードをタップ → 大きな画像が開く → 右クリックメニューで「画像を保存」 | ④ タップ → 右クリックで保存 |
| 23.0–26.4 | まとめて | ZIP一括ダウンロードのリンク。862枚がフォルダにドサッと入る演出 | まとめてなら **ZIPで862枚** |
| 26.4–30.0 | 締め | ロゴ + URL + 利用条件 | ワークシートにも、スライドにも。<br>学校の授業なら自由につかえます |

## 制作メモ

- **実録画ではなく、実画面のスクリーンショット + Remotion合成**で作っている。
  15〜30秒のCMは広告の文法(フラッシュ・大きいコピー・カットで語る)が要るのと、
  Playwrightの録画が実質25fpsでカクつくため(スキル `remotion-app-video` のジャンル判定に従った)。
  スクロール・入力・タップは、実画面の**フルページスクショをRemotion側で毎フレーム動かして**表現しているので、
  全編きっちり30fpsで滑らかに出る。
- 画面は `index.html` と `cards.html` の**実物**をローカル配信して撮影したもの。
  絵カード画像は PictureDictionary リポジトリのクローンから差し込んでいるため、
  **公開環境と同じく実画像で表示**されている(前回の `portal_pr_movie.mp4` は絵文字フォールバックだった)。
- 「右クリック → 画像を保存」のメニューは、OSのネイティブメニューがスクショに写らないため
  **Remotion側で再現**している(ブラウザの実際の項目名に合わせた簡略表示)。
- BGMはスクリプトで合成したオリジナル曲(権利上の問題なし)。ナレーションなし。
